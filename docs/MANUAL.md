# Behemiron Jolt Physics 插件使用手册（建模师版）

> 写给 BlockBench 建模师：不需要懂物理、不需要懂 Jolt。跟着第 2 章做一遍摆锤，你就什么都会了。

---

## 第 0 章 · 这东西能干什么

**30 秒版**：给你的 BlockBench 模型打上物理标签，模型在游戏里就是**真物理**——门会绕铰链 swinging、箱子会堆叠翻滚、车能开、果冻会抖。不用写代码，全部在 BlockBench 里点出来。

**模型怎么就有了物理？** 一张流程图：

```
你在 BB 里建模（骨骼+方块）
        ↓ 给骨骼设物理属性、骨骼间加"约束"（关节）
保存 .bbmodel  ← 物理数据自动存在文件里（jolt_physics 字段）
        ↓
游戏引擎读同一个文件 → Jolt 物理世界里你的模型活了
```

你交付给程序的**只有一个 .bbmodel 文件**，物理数据全在里面。

## 第 1 章 · 安装与界面导览

### 1.1 安装

把 `dist/behemiron_jolt.js` 拖进 BlockBench 窗口 → 点"允许"。完了。

- 桌面版（Windows/macOS/Linux）和网页版都能用，**离线可用**（物理引擎已打包在插件里）。
- 更新插件：把新文件再拖一次，或在插件菜单里选 Reload。

### 1.2 三个新东西在哪

1. **右栏"JOLT 物理"页签**（和大纲并排）：选中什么就显示什么——这是你的主工作面板。
2. **Tools 菜单 → Jolt Physics 子菜单**：模拟播放/暂停/单步/重置、新建约束、烘焙、检查点。
3. **视口里的彩色线条**（gizmo）：选中的模型有物理约束时，视口会画出轴线和圆圈——那是约束的"结构图"，第 6 章教你怎么读。

### 1.3 语言

插件跟随 BlockBench 的语言设置，中文英文自动切换。

## 第 2 章 · 五分钟上手：做一个摆锤

跟着点一遍，全程不超过五分钟。

1. **新建模型**（任意格式，推荐 bbmodel）。
2. **建一个 Group（骨骼）**，命名"摆锤"。里面放一个方块，随便什么形状。
3. **再建一个 Group**"支架"，放一个长条方块当地面支架。
   把两个骨骼摆成：支架竖着，摆锤吊在支架旁边，离支架远一点（中间空着）。
4. **选中"摆锤"骨骼** → 右栏 JOLT 物理页签 → 运动类型选 **动态**（默认就是）。
   → 这就是"这个骨骼是个自由的物理体"的意思。
5. **选中"支架"骨骼** → 运动类型改 **静态**（Static）——它不动，只提供碰撞。
6. **同时选中两个骨骼**（Ctrl 点选两个 Group）→ Tools → Jolt Physics → **New Constraint** → 类型选 **Hinge（铰链）** → 确认 → 在弹出的编辑器里直接再确认。
   → 视口出现了轴线和小圆圈，锚点自动填在两骨骼中心——先别管细节。
7. Tools → Jolt Physics → **Toggle Physics Simulation**（或记住以后用菜单点）。

**预期现象**：摆锤掉下来，绕着和支架相连的点摆动，慢慢停下。

8. 想停：**Reset**（工具菜单）——模型还原到模拟前的样子，一个像素都不改。

恭喜，你已经用了这个插件 90% 的功能。下面教你每个开关到底是什么。

## 第 3 章 · 核心概念（不懂物理也能懂）

### 3.1 刚体 = 你的 Group

- **一个顶层 Group（骨骼）= 一个物理"刚体"**。刚体就是"一块不会变形的硬东西"。
- Group 里面的方块/网格自动成为这块刚体的碰撞形状，**不用你一个个指定**。
- Group 里面嵌套 Group？里面的东西自动算到最外层刚体上（一个整体）。
- 不在任何 Group 里的散立方体，每个自己当一个刚体。

**一句话**：你的骨骼结构就是物理结构，建模习惯不用改。

### 3.2 碰撞形状：看得见的模型 ≠ 物理碰撞

物理引擎不看你的方块长什么样，它只看"碰撞形状"。插件给每个元素自动生成：

| 形状 | 是什么 | 什么时候出现 |
|---|---|---|
| **Box** 方块 | 方块的最小包围盒 | 方块设 Auto（默认） |
| **Convex Hull** 凸包 | 包住网格的"紧身膜" | 网格设 Auto |
| 球/胶囊/圆柱/锥形系列 | 从包围盒推出来的规则体 | 你手动选 |
| **Mesh** 三角网格 | 逐三角形的精确碰撞 | 你手动选（大网格专用） |

**新手原则：全部 Auto**。只有当你发现"该穿过去的地方被挡住了"（碰撞太肥）或"该挡住的地方漏了"，才回来改形状。改法：选中元素 → 面板"碰撞形状"下拉。

### 3.3 三种运动类型（什么时候动、什么时候不动）

| 类型 | 人话 | 典型用途 |
|---|---|---|
| **Static 静态** | 焊死在世界上，永远不动 | 地面、墙、支架 |
| **Dynamic 动态** | 完全受物理摆布（重力、碰撞、推力） | 箱子、摆锤、零件 |
| **Kinematic 运动学** | 你让它去哪它就去哪，但能把别人撞飞 | 动画驱动的门/平台 |

> 特殊：设了"由动画驱动"勾选的 Kinematic 骨骼会跟着你的 BB 动画走，同时推动别的物理体（见 7.2）。

### 3.4 约束 = 关节（两个骨骼之间的连接）

两个独立的刚体，靠什么连起来？**约束**。用生活里的东西类比：

| 约束 | 类比 | 一句话用途 |
|---|---|---|
| Fixed 固定 | 胶水 | 两骨骼焊死成一个 |
| Distance 距离 | 绳子 | 两点距离被限制（吊牌、秋千） |
| Hinge 铰链 | 门轴/合页 | 只能绕一根轴转（门、摆、风扇）★最常用 |
| Slider 滑轨 | 抽屉轨道/活塞 | 只能沿一根轴平移 |
| Point 点 | 万向节 | 两点拴在一起，自由乱转（吊灯） |
| Cone 锥 | 球窝+限位 | 像肩膀一样在一定锥角内活动 |
| SwingTwist | 肩膀+拧毛巾 | 锥形限位再加"扭转角度"限制 |
| SixDOF 六自由度 | 万能关节 | 6 个方向各自设限位（高级） |
| Pulley 滑轮 | 定滑轮 | 一根绳两端挂两物体，此消彼长 |
| Gear 齿轮 | 齿轮啮合 | 两轴转速按比例联动 |
| RackAndPinion | 齿轮齿条 | 旋转⇄直线互相转换（方向盘→车轮转向） |
| Path 路径 | 轨道 | 刚体被限制在一条空间曲线上滑动（引擎侧使用，编辑器里只标注） |

### 3.5 单位和尺度

- 你的模型按 **Minecraft 惯例：16 单位 = 1 米**（面板"无选择"状态可改）。
- **90% 的情况不用管单位**——插件内部自动换算。例外：你要和程序对齐"这个游戏里 1 格是不是 1 米"时，确认一下"每米单位数"设置即可。

## 第 4 章 · 日常：给模型打物理标签

### 4.1 标准工作流

```
建模（分好骨骼） → 选骨骼设属性 → （需要时）双选建约束 → 模拟试玩 → 保存 → 交付
```

### 4.2 面板逐项（人话版）

选中骨骼，右栏"JOLT 物理"只有四项 + 两个按钮——这是**刻意设计**，最常用的才放外面：

| 面板项 | 人话 | 调大效果 | 新手建议 |
|---|---|---|---|
| 运动类型 | 见 3.3 | — | 会动的选动态，不动的选静态 |
| 摩擦 | 防滑程度 | 0=冰面，1=橡胶 | 0.2~0.6 都行 |
| 弹性 | 蹦床程度 | 0=不反弹，1=完美反弹 | 0~0.3，橡皮球才上 0.8 |
| 控制器 | 特殊玩法 | 见第 7 章 | 普通刚体保持"无" |

**〔刚体属性…〕按钮**打开对话框，里面的进阶项（90% 的模型不需要碰）：

| 进阶项 | 人话 | 什么时候碰 |
|---|---|---|
| 物体层 | 碰撞分组编号 | 程序要求分碰撞组时 |
| 线性阻尼 | 空气阻力（挡平移） | 东西滑太远、想更"沉稳" |
| 角阻尼 | 空气阻力（挡旋转） | 东西转个不停 |
| 重力系数 | 1=正常重力，0=失重，-1=往上飘 | 气球、幽灵 |
| 运动质量 | 离散/线性投射 | 会高速穿模的小物体选"线性投射" |
| 传感器 | 只触发不碰撞 | 做触发区（见 7.4） |
| 允许睡眠 | 不动时停止计算 | 永远开着 |
| 质量属性/质量 | 手动指定质量 | 程序要求精确质量时 |

### 4.3 保存即交付

Ctrl+S 后物理数据存在 .bbmodel 的 `jolt_physics` 字段里。**你交付 .bbmodel，程序直接用**——没有导出步骤，不会忘。

## 第 5 章 · 约束全书

### 5.1 通用操作（所有约束共用）

1. **同时选中两个骨骼**（Ctrl 加选两个 Group）。
2. Tools → Jolt Physics → New Constraint → 选类型 → 确认。
3. 弹出编辑器，按 **Anchors（锚点）→ Limits（限位）→ Motor（马达）** 分组：
   - 锚点：两个物体上的连接点。默认已自动填在两头中心，**直接用**。
   - 轴向：铰链绕哪根轴转、滑轨沿哪根轴滑。默认 Y 轴/世界方向，90% 不用改。
   - 限位：角度单位是**度**，长度单位是**模型单位**。留空 = 不限。
   - 马达：见 7.1。
4. 确认。视口出现 gizmo。
5. **拖锚点**：编辑模式下，锚点位置有个小方块手柄，按住拖到想要的位置（数值会同步）。
6. 想改：单击 gizmo（点一下，别拖拽）重新打开编辑器；或在面板约束列表点条目。

### 5.2 Fixed 固定（胶水）

- **干什么**：两骨骼焊死。为什么要焊？有时你想让两个骨骼物理上是一体但建模上分开。
- **参数**：锚点两组 + 自动定位开关。基本全默认。
- **例子**：把武器"粘"到旋转平台上一起转。

### 5.3 Distance 距离（绳子）

- **干什么**：限制两锚点的距离范围——最短多少、最长多少。像一根不会拉断、不会缩短的绳。
- **关键参数**：最小距离 / 最大距离（留空=不限那一端）。创建时最大距离自动填了两点间距。
- **例子**：吊灯（最大距离=灯到天花板的距离）、吊桥悬索、悠悠球。

### 5.4 Hinge 铰链（门轴）★最常用

- **干什么**：两个物体绕一根公共轴相对转动。门、摆、风扇、活板门。
- **关键参数**：
  - 铰链轴：默认竖直（Y）。门要水平开就把轴改成竖直的另一个方向……实际按你模型的朝向试一次就懂。
  - 限位 min/max（度）：门只能开 90°？填 -90 和 0。留空=360° 自由转。
- **例子**：第 2 章的摆锤。限位 -90~90 就是一个来回摆的门。

### 5.5 Slider 滑轨（抽屉）

- **干什么**：两物体沿一根轴相对平移，其他方向锁死。抽屉、活塞、电梯导轨。
- **关键参数**：滑轨轴（默认 Y，多半要改）、限位（**长度**，不是角度——滑出多少模型单位）。
- **例子**：炮管后座（限位 0~4）、滑门。

### 5.6 Point 点（万向节）

- **干什么**：两锚点拴在同一点，随便转。任何方向的"挂钩"。
- **参数**：只要两个锚点，全默认。
- **例子**：吊灯、拖车钩。

### 5.7 Cone 锥（球窝限位）

- **干什么**：像肩膀/髋关节：可以大角度活动，但最多只能转到某个"锥角"内。
- **关键参数**：锥半角（度）。90°=随便转，30°=小范围。
- **例子**：机械臂末端、吊臂。

### 5.8 SwingTwist（肩膀+拧毛巾）

- **干什么**：Cone 的加强版：摆动范围（两个方向的锥角）**加上扭转范围**（像拧毛巾的上下限）。
- **关键参数**：法向半锥角 / 平面半锥角 / 扭转 min/max（度）。
- **例子**：人形生物的肩膀、炮塔座圈。

### 5.9 SixDOF 六自由度（万能关节）

- **干什么**：前 3 个方向（X/Y/Z 平移）+ 后 3 个方向（绕 X/Y/Z 旋转）**各自独立**设限位或锁死。一个约束顶所有。
- **怎么填**：限位 min/max 是 6 个逗号分隔的数，**前 3 个是长度（模型单位）、后 3 个是角度（度）**，留空=该方向自由。
- **例子**：机械手腕、模拟人的脊椎骨（逐节 SixDOF）。

### 5.10 Pulley 滑轮

- **干什么**：一根虚拟绳子跨过两个固定点，两端各挂一个物体——一头升高另一头必降。
- **关键参数**：物体挂点 1/2（跟着物体走）、固定点 1/2（在世界里的滑轮位置，创建时自动填在各自上方）。
- **例子**：矿井升降机、老式水井辘轳。

### 5.11 Gear 齿轮

- **干什么**：两个旋转轴转速按比例联动（正比例）。
- **关键参数**：两轴方向 + 传动比（1=同速，2=一倍速差）。
- **例子**：齿轮组、机械表。

### 5.12 RackAndPinion 齿轮齿条

- **干什么**：一个物体的**旋转** ⇄ 另一个物体的**直线滑动**，严格按比例。
- **关键参数**：齿轮轴（旋转）、齿条轴（平移）、传动比=每弧度滑多少米。
- **例子**：方向盘带车轮转向、闸门绞盘。

### 5.13 Path 路径（引擎侧）

- **干什么**：把一个物体限制在一条空间曲线上运动（过山车轨道）。
- **编辑器现状**：参数可完整编辑（路径点逐行填 x,y,z），编辑器内模拟暂不支持（标签会注明）。**数据完整，游戏里正常**——路径物理在你引擎里跑。

## 第 6 章 · 模拟与调试

### 6.1 五个控制

| 操作 | 干什么 |
|---|---|
| Toggle（播放/暂停） | 开始模拟 / 暂停（数据和 ghosts 都冻结） |
| Step 单步 | 暂停时每次前进 1/60 秒，逐帧看细节 |
| Reset 重置 | 停止并完全还原模型，开始改模型前先 Reset |
| Save Checkpoint 存检查点 | 存档（当前物理状态快照） |
| Restore Checkpoint 读检查点 | 读档回快照——调试神器："刚才那一步之前发生了什么？" |

### 6.2 读懂视口 gizmo

- **三色**：浅蓝 = 骨骼 A 侧，青色 = 骨骼 B 侧，主题色（橙）= 公共结构/锚点手柄。
- **铰链**：一条轴线 + 两个限位圆弧（角度范围直接画出来，半透明的双圆）。
- **滑轨**：一条轨道线 + 两端限位刻度。
- **虚线**（模拟中）：速度方向；**圆点**（模拟中）：传感器，实心=正在被触发。
- 跟当前选中骨骼相关的约束会**高亮**，其余淡下去。

### 6.3 地面和重力

面板"无选择"状态：地面开关（默认开，模拟时在模型最低处铺一块看不见的地板）、重力向量（默认 -9.81，改 0 就是太空）。

### 6.4 性能常识

- 几百个刚体毫无压力（基准：200 个盒子实时 40 倍以上速）。
- 不动的物体会自动"睡着"省性能——别奇怪它们怎么不动了，碰一下会醒。
- 大网格（几万面的车壳）碰撞很贵：**碰撞形状选凸包或 Box**，Mesh 只给真正需要的静态地形。

## 第 7 章 · 进阶玩法

### 7.1 马达（让关节自己动）

Hinge 和 Slider 编辑器里有 **Motor** 分组：
- 状态：**关闭 / 速度 / 位置**。
  - 速度：以目标速度一直转（°/s 或 模型单位/s）→ 风扇、车轮、传送带。
  - 位置：努力转到目标角度/位置 → 舵机、自动门。
- 最大力矩/力：马达的"力气"，防卡死也防失控。默认 0=不限。

### 7.2 动画驱动刚体（Kinematic）

骨骼属性对话框（刚体属性…里的进阶区……实际入口：面板运动类型选 Kinematic 后，"刚体属性…"对话框中勾选）**"由动画驱动"**：
- 播放模拟时，这个骨骼跟着你的 BB 动画走，同时把别的动态刚体撞开。
- 例子：做一段"门推开"的动画，门是 Kinematic+由动画驱动，门后的箱子被真实撞飞。

### 7.3 烘焙：模拟 → 动画关键帧

1. 摆好场景，Reset 状态。
2. Tools → Bake Physics to Animation → 填名字/时长/采样率（20fps 够用）→ 确认。
3. 等进度条走完 → **Animations 面板出现新动画**，关键帧可直接用于导出（GeckoLib 等任何 BB 动画流程）。

用途：物理演算一次，结果当**手工打磨过的动画**交给动画师，游戏里零物理开销。

### 7.4 传感器（触发区）

"刚体属性…"里勾**传感器**：这个物体不再阻挡任何东西，但**穿过的瞬间程序能收到事件**（编辑器里表现为视口圆点变实心）。
用途：踏板、触发区域、计数区。具体事件逻辑由游戏程序处理。

### 7.5 车辆

1. 车身 = 一个 Group，**四个轮子各是一个子 Group**（放在车身的四角，位置即轮位）。
2. 选中车身 → 控制器选 **Vehicle** → 〔编辑参数〕：
   - Engine：最大扭矩 / 转速区间（马力大小）
   - Transmission：档位数量、换挡时间、离合强度
   - Wheels：轮半径/宽、转向角
   - Suspension：悬挂行程、弹簧频率/阻尼（软硬）
   - Brakes：刹车力矩、轮胎摩擦
3. 播放模拟 → **WASD 开，空格刹**。

调车感口诀：打滑→加轮胎摩擦或降扭矩；弹跳→加悬挂阻尼；转向不灵→加转向角。

### 7.6 软体（果冻/旗帜）

1. 骨骼控制器选 **Soft Body**。这个骨骼里的**每个方块自动变成一个体素**，整块变成 FEM 软体。
2. 〔编辑参数〕：边/弯曲/体积柔度（越小越硬）、弯曲类型、顶点质量。
3. 模拟：整块果冻下落、弯折、颤动。
4. **钉住顶点**（让软体挂在骨骼上）：用 BlockBench 自带的**权重绘制**（Armature 骨架功能）给骨骼刷顶点权重——权重满值的顶点会被钉住，软体就挂在上面晃。

### 7.7 毛发

骨骼控制器选 **Hair** → 〔编辑参数〕：发束数量、每股段数、长度、根环半径、迭代率（360=顺滑）、弯曲柔度、LRA（防拉伸）。
参数与引擎共享同一个确定性生成公式——你在编辑器里看到的形状就是游戏里的形状。
**已知限制**：编辑器内模拟暂不支持（初始化正常，步进会冻结并提示）；引擎（jolt-jni）里完整可跑。

### 7.8 角色

骨骼控制器选 **Character**：胶囊体参数（半径/高）、坡度限制、跳跃速度等。
**已知限制**：编辑器内行走暂不可用（等待上游绑定更新）；数据完整，引擎侧正常。

## 第 8 章 · 交付与验收

### 8.1 交付物

**就一个 .bbmodel 文件**。物理标签、约束、控制器参数全部在里面。

### 8.2 程序侧怎么读（给建模师的一页纸版）

程序用 jolt-jni 解析 bbmodel 里的 `jolt_physics` 字段，重建物理世界：

## 第 9 章 · 常见问题 FAQ

**Q1 按播放什么都没动？**
检查三点：①骨骼是不是顶层 Group（套在别的组里的骨骼会合并成外层的一部分）；②运动类型是不是"动态"；③是不是被地面接住了（模型最低点以下自动铺地面）。

**Q2 模型一飞冲天/乱飞？**
弹性调低（0.3 以下）；或者两个物体初始就穿插（建模时留缝）；或者刚体里有"隐藏元素"导出关掉的检查一下。

**Q3 两个东西该连着却分开了？**
约束锚点对不上。单击 gizmo 打开编辑器，把两个锚点都拖到实际的连接位置（比如门的合页处）。

**Q4 门穿过墙/穿模？**
碰撞形状太肥：把门和墙的元素形状从 Box 改成凸包；小物体高速穿墙：运动质量改"线性投射"。

**Q5 数值连点反应慢？**
已修复（90 毫秒合并）。还慢的话把面板数字直接键盘输入。

**Q6 模拟时编辑面板被锁了？**
设计如此——模拟不碰模型数据。Reset 后再编辑。

**Q7 撤销（Ctrl+Z）对物理属性无效？**
已知限制：BB 插件体系不支持撤销物理标签编辑（约束删除有确认）。改动前保存。

**Q8 摆锤越摆越高？**
马达"速度"状态配了目标速度+限位=自己在做功。把马达关掉或检查限位。

**Q9 车辆打滑/翻车/跳？**
7.5 口诀：轮胎摩擦↑、悬挂阻尼↑、扭矩↓、重心调低（轮子/车身布局）。

**Q10 软体一模拟就消失？**
检查骨骼里是不是有网格元素混进软体组（软体只吃方块）；钉子（满权重顶点）至少留一个或允许全自由落体。

**Q11 约束列表在哪看全部？**
面板"无选择"状态（点空白处）底部列出所有约束。

**Q12 怎么删约束？**
打开该约束的编辑器 → 底部勾"删除此约束" → 确认。

**Q13 做出来的物理和引擎里不一样？**
锚点/角度在编辑器是 BB 单位/度，引擎自动换算——两边读取同一份数据，理论一致。差异只可能来自引擎侧用了不同的单位设置（找程序对一下"每米单位数"）。

**Q14 一发丝/角色/路径在编辑器没反应？**
见 7.7/7.8/5.13 的已知限制——数据是全的，游戏里是活的。

**Q15 插件提示 Jolt WASM 加载失败？**
基本不会发生（引擎已内嵌）。真出现了也能用：导出和编辑不受影响，只有模拟禁用。重启 BB 再试。

**Q16 能不能只给模型的一部分加物理？**
能。不做任何设置的骨骼不会被当成物理体；只有设过属性的顶层骨骼才进物理世界（实际上所有顶层骨骼都会进——完全不想要的挪进别的组或关掉"参与"）。

**Q17 单位比例不是 16 怎么办？**
面板"无选择"状态改"每米单位数"（比如做真实比例模型用 100）。

**Q18 想做一个 200 块零件的机器人？**
可以。建议：相邻零件用 Fixed/Hinge 连接，马达参数从小往大试，先 10 个零件调通了再堆量。

**Q19 模拟很卡？**
看状态条的 jolt 对象数（模拟时显示，应该恒为 0；不是 0 找开发）。物体太多时把不动的都设静态。

**Q20 更新插件后旧模型还能用吗？**
能。物理数据版本化存储，向后兼容。
